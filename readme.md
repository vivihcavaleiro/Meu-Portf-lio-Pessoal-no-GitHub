# Portfólio Pessoal - Desenvolvimento Web

Este projeto é um site de portfólio pessoal desenvolvido com HTML5 e CSS3 como parte de uma atividade prática.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout responsivo e animações com `:hover`.
- **GitHub Pages**: Hospedagem e publicação do projeto.

## 📌 Funcionalidades
- Cabeçalho com foto e informações de perfil.
- Menu de navegação fixo com âncoras internas.
- Apresentação pessoal com mais de 10 linhas.
- Lista de habilidades destacadas.
- Cards interativos de projetos com sombras e efeitos.
- Informações de contato e redes sociais.
- Layout responsivo adaptado para celulares e computadores.
